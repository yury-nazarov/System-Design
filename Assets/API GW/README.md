# API GW

API Gateway (API GW) — это сервис‑шлюз, который выступает единым входом для клиентских запросов к множеству бэкенд‑сервисов (в т. ч. микросервисов).

![](./API%20GW%20B.png)

## Основные функции:

- **Маршрутизация запросов** — перенаправление входящих запросов к нужным сервисам, в том числе по HTTP Header.
- **Аутентификация и авторизация** — проверка прав доступа (например, через JWT‑токены). Взаиможействие с IDM(Identity Management) провайдером.
- **Rate Limiting** (Ограничение частоты запросов) — защита от перегрузки и злоупотреблений.
- **Валидация запросов** — проверка формата и корректности данных до их передачи в сервисы.
- **Агрегация данных** — объединение ответов от нескольких сервисов в один ответ клиенту.
- **Логирование и мониторинг** — сбор статистики, отслеживание ошибок и трассировка запросов (например, с присвоением Trace ID).
- **Трансформация протоколов и данных** — конвертация между REST и gRPC, адаптация форматов.
- **Кэширование** — временное хранение (часто в отдельном InMemory store) часто запрашиваемых данных для ускорения ответов.
- **Обработка ошибок** — унифицированное формирование сообщений об ошибках для клиента.
